# SceneFlow Tools
This repository contains unity tools and scripts for SceneFlow.

Unity Version: 2022.3.53

The Editor functionality relies on the external service SceneFlowDevService. After deployment, configure the service address in ExternalServiceSettings.

## Features
- Voxelization-based semantic scene clustering
- LLM-driven script analysis for latency sensitivity profiling
- Multi-user-aware partitioning under resource constraints
- Runtime render config load and scene setup
